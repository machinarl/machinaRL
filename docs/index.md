## Core Concepts

### Evolution System
The platform features a 7-stage evolution ladder:
1. **Primitive** - Basic reactive behaviors
2. **Composite** - Integration of multiple behaviors
3. **Limb-Bearing** - Control of articulated bodies
4. **Advanced Mechanica** - Complex motor control
5. **Winged/Gliding** - Aerial dynamics mastery
6. **Hybrid** - Multi-modal intelligence
7. **Ascendant** - Peak performance and strategic mastery

### Simulation Types
- **Maze Navigation** - Pathfinding and spatial reasoning
- **Obstacle Courses** - Dynamic environment navigation
- **Climbing Challenges** - Vertical movement and grip mechanics
- **Object Manipulation** - Push, pull, and carry operations
- **Pyramid Building** - Construction and stacking logic
- **Food Collection** - Resource gathering and optimization
- **Hallway Navigation** - Confined space movement
- **Gridworld** - Discrete state space navigation
- **Walker** - Bipedal locomotion
- **Crawler** - Quadrupedal movement
- **Ball3D** - 3D physics and dynamics

## Development

### Architecture
- **Frontend**: Next.js 14 with TypeScript and Tailwind CSS
- **Styling**: ASCII/terminal aesthetic on white background
- **Unity Integration**: WebGL builds for 3D simulations
- **API**: RESTful endpoints for simulation management
- **Data**: JSON-based storage for results and leaderboards
